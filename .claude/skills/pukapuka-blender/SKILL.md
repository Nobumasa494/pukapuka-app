## 2. 今のシーンの作り方（v20）

### オブジェクト
| 名前 | 内容 |
|---|---|
| Ground | 地形 62×62 / 間隔0.55（±17）、SUBSURF L3、フラットシェード |
| FarGround | ±16〜±46 の遠くの地面（間隔1.0）。地面の端を見せないため |
| River | 水面の一枚シート ±17（間隔0.38）、z=-0.14、Wave×2、フラットシェード |
| FarWater | 遠くの水面の板 ±46、z=-0.15（波なし） |
| Tree_* / FarTree_* | v9 の木（TreeA/B/C を使い回し）／遠くの森 |
| Bushes / Reeds / Flowers | 茂み・ガマ・花（各1メッシュ、ローポリ） |
| Rock_* / BankRock_* | 岩 |
| Mtn_0〜3 | 地平線の向こうの薄い山並み（v21B）。画面 x 0.12/0.40/0.80/1.02、距離 78/92/80/70、z=-1.0、scale (5,4,.55)/(4,3.4,.40)/(4.6,3.8,.50)/(3.8,3.2,.45)。頂上が画面の上から21〜23% |
| SunDisc / SunHaloObj | 太陽と光の輪（板） |
| RiverCam / Sun / Ambient / RimLight | カメラと3灯（全部 SUN） |

色は sRGB で書く。`s2l(v)= v/12.92 if v<=0.04045 else ((v+0.055)/1.055)**2.4` で linear にして入れる。

### カメラ・レンダー
- RiverCam: 位置 (7,7,4)、lens 26、回転 (66.7°, 0°, 130.75°)。川の曲がり角が画面の上から34%、地平線19%、水面が画面の約7割
- EEVEE（`BLENDER_EEVEE`）、1080×1920、24fps、96フレーム（4秒ループ）、色管理 Standard

### 光と空（黄昏）
- 太陽: 画面 (x0.60, 上から20.5%) を通る視線上の距離60に SunDisc / SunHaloObj（`cam.data.view_frame()` の4隅を補間して視線を作る）
- Sun: 太陽と同じ方位・仰角9°、color (1.0,.60,.34) energy 3.3、angle 0.09、specular 0.12
- Ambient (.52,.56,.95) 1.55 影なし / RimLight (1.0,.50,.42) 1.0 影なし
- 空: `TexCoord.Normal → SeparateXYZ.Z → MapRange(From 0 → -0.45) → ColorRamp → Background`。ColorRamp `0 (1.0,.80,.55) / .10 (.99,.64,.46) / .28 (.88,.52,.58) / .55 (.55,.44,.72) / 1.0 (.22,.24,.50)`
- 霞: 各マテリアルに `CameraData.ViewZDepth → MapRange → Mix Shader Fac`、霞色 (.98,.76,.66)。start は18以上

### 川の中心線と地形
- 中心線 CL は `scene["CL"]` に JSON で保存済み（0.5刻み181点、ゆるいS字）。`json.loads(scene["CL"])`
- 弧長 sv、川幅 `HW(sv)=1.55+0.22*sin(sv*0.31+0.7)`
- 地形の高さ（中心線までの距離 d）:
```python
hill=0.30*sin(x*0.20+1.1)*cos(y*0.17-0.6)+0.16*sin(x*0.38-2.0)*sin(y*0.33+0.8)+0.08*cos(x*0.63+0.3)*cos(y*0.57-1.4)
if d<HW: z=-0.55
else: z=-0.55+0.95*ss(HW,HW+2.3,d); far=max(0,d-(HW+2.3)); z+=0.045*far+hill*min(1,far/3.5)
```
- **FarGround** は同じ式で、上り坂だけ外側で止める: `rise=0.045*far-0.045*max(0,far-5)*ss(16,22,r)`（r=max(|x|,|y|)）、z を -0.01 下げて継ぎ目を隠す。**沈めると地平線まで湖に見える（失敗済み）**

### 水面
- 一枚シートを地面の下に敷く（岸の線＝地面と水の交線＝なめらか）。v9 の三角形の質感のため `use_smooth=False`
- WaveMask（頂点グループ）: `(1-ss(EDGE-0.9,EDGE-0.25,d))×(0.55+0.45*ss(14,34,sv))`、EDGE=HW+1.05
- 波2枚（`time_offset=-8000` 必須、`speed=2*width/T` で T が96の約数なら完全ループ）: WaveA 開始(-46,-40) h0.105 w1.15 T96 narrow1.2 / WaveB (20,-55) h0.048 w0.65 T48 narrow1.8
- WaterFacet: Mix(Add(Emission str0.30, Diffuse (.13,.39,.48)), Glossy rough0.30)
  - Emission 色 = フレネル（`LayerWeight Blend0.55 Facing → MapRange(0.15→1.05, SMOOTHSTEP)`）で水色 (.13,.40,.50)→夕焼け (.95,.66,.62)
  - 浅瀬: 点属性 `shore=ss(EDGE-1.0,EDGE,d)` ×0.75 で (.36,.70,.68)、`MapRange(0.90→0.99, 0→0.5)` でクリーム色の細い線
  - Glossy の Fac は `ViewZDepth → MapRange(4→19, 0.006→0.042)`（照り返しは奥だけ）
  - `River.visible_shadow=False`

### 木と配置
- 木: 幹（6角コーン）＋ icosphere subdiv1 の葉2〜3個、フラットシェード、葉 LeafA (.40,.55,.26) / LeafB (.30,.46,.24)、幹 Bark (.42,.30,.23)
- 群れと抜け（奇数本、主木が一番大きい、水辺の孤木、手前左の額縁の木）。泡の通り道を隠す木は川から離した（v17）
- 岩 Rock (.55,.54,.52)（明るいと夕日でピンクに見える）
- 草地 Ground: Diffuse 色に `Noise(Object, scale0.35) → ColorRamp(暗×0.80〜0.86 / 明×1.14〜1.22)`
- 茂み Bushes: icosphere subdiv1 を2〜3個寄せた塊×15か所、LeafA/B
- 遠くの森 FarTree_*: sv 40〜62。**|x| か |y| が14より外には置かない**（空に浮く）
- ガマ Reeds: カーブ内側（曲率大の4か所）の浅瀬 d=HW+0.85〜1.2 に5・7・9本の株。中央が高い、少し傾く、穂は7割
- 花 Flowers: 見えている岸に「花畑」5つ（川の向きにσ0.75・横にσ0.28、26〜40輪、白と桃の割合を花畑ごとに変える）＋まばらな一輪18。**中心は画面上の点から ray_cast で決めた**

### アプリ連携（泡）
- 通り道 river_path.json: 中心線を画面座標に投影（`x,y` 0〜1・y下向き、`halfw` 川幅の半分、`depth`、`visible`）。**カメラ・川を変えたら書き出し直す**
- 泡の大きさ（奥でも読める）:
```js
const persp=p.halfw*W*0.44*(0.85+0.06*len);
const tt=clamp((p.y-.33)/.3,0,1);              // 0=奥 1=手前
const minFit=10*len/0.82+4;                    // 文字10pxが1行で入る最小
size=min(100, max(minFit*(0.9+0.1*tt), 40+(persp-40)*tt, persp));
```
- 奥の泡も薄く・ぼかさない（opacity 0.8〜1）。列の間隔は泡の大きさ×0.92、横は川幅に入るだけ（×1.12ごと、最大3）
- 泡の見た目: 上の縁に暖色の内側の線、下に水色の影、下に楕円の波紋2重＋淡い映り込み、小さな光点1つ、文字は折り返さない、メニュー手前でフェードアウト
- 見本: 背景＋JSON の HTML をプロジェクトの Playwright で 375×667 撮影（`file://` では fetch 不可なので `addInitScript` でデータを渡す）。作業用ファイルはスクラッチパッドの `mock.html` / `shot.mjs`

## 3. 作業のルール（必須）

### 順序
1. このファイルの「1. 今の版」と「2.」を読む（古い数値が必要なら HISTORY.md）
2. 変える前に .blend を番号付きで保存（`compress=True, copy=True`、保存先 Documents\pukapuka_blender）
3. 変更 → **数値で確認** → 半分の解像度で静止画を撮る → 自分で前の版と並べて差を確かめる
4. 問題があれば原因を特定してこのファイルを更新し、3に戻る
5. 完了報告（静止画を見せて止める）。**動画はユーザーがOKした後に1回だけ**
6. 「作業時間の記録」に1行追記

### 物を置いたら必ずやる確認（撮る前・省略しない）
v18・v19 で「ルールはあるのに新しい物に当てはめ忘れて撮り直し」が続いたため、**置く作業の最後に毎回この4つを数値で確かめる**:
1. **画面に映るか**: `world_to_camera_view` で画面内の割合と、画面の高さ（奥の30〜40%だけに集まっていないか）
2. **泡の通り道を隠さないか**: 中心線の筋（±0.7・0 ×HW）を画面の高さ31〜70%でカメラから `scene.ray_cast`
3. **地面の端・空に浮かないか**: |x|,|y|≤14、地面に接地（`Ground.ray_cast` で高さ）
4. **見せたい物は画面上の点から位置を決める**（画面を格子で `scene.ray_cast` → Ground に当たった点を候補に）

地形を変えたら、**全体を1枚撮って地平線と画面の端まで確かめる**（v20 で遠くの地面を沈めすぎ、地平線まで湖になった）。

### 速く・品質を落とさずに
- 確認用は `resolution_percentage=50`。最終の1枚と動画は100に戻す
- 撮る前に数値で確認。小さな修正はまとめて1回で撮る
- 原因が分からないときは怪しい物を `hide_render=True` で隠して1枚撮る
- 一部だけ見るときは範囲レンダリング（`use_border` / `use_crop_to_border`、終わったら必ず False）
- 画面の点→地面: `p=tl.lerp(tr,sx).lerp(bl.lerp(br,sx),sy)`（`view_frame` の4隅）を z=-0.14 の平面か `scene.ray_cast` に落とす
- 中心線との距離は KDTree で近い点を探し、前後2区間だけ調べる（総当たりしない）
- 構図だけの確認では SUBSURF の `render_levels` を一時的に下げる
- 好みで決まる修正は2〜3案を並べて1回で選んでもらう。案は**見て違いが分かる幅**で作る
- 変わっていないデータ（泡の通り道など）は使い回す
- ファイル操作はまず `cp` だけにして、加工は別に行う（v20 で sed の一括処理を誤り、履歴ファイルを空にした）

### ファイル
- 見せた画像は previews に**直近5版**（基準 v9 は消さない）。6版目で一番古い版を消す
- **ユーザーに送る画像はスクラッチパッドにコピーしてから SendUserFile**（Documents 直接は「Couldn't load this file」）
- 作業用の静止画は Temp の `pk_tmp.png` を上書きで使い回し、報告後に消す
- 動画は最新1本だけ Temp に残し、OK後に Documents へ。連番フォルダは MP4 にしたら消す。.blend は消さない
- 消すのは自分が作った `pk_*` だけ

### 完了報告の形
```
【見つけた問題点】／【根本原因】（「○○だから△△」）／【修正】／【SKILL.mdに追記した内容】／【修正後の確認】（動画はOK待ちと明記）
```
気になる点はまとめて・スクショで場所を示してもらうよう最後に添える。

### このファイルの更新
- 再発防止 → NGパターン。今の設定 → 「2.」を書き換える（古い内容は消して HISTORY.md に残す）
- 既存ルールと同じことは追記せず書き直す。症状ではなく原因で書く

## 5. NGパターン

### Blender 5.2 API
- `BLENDER_EEVEE_NEXT` → `BLENDER_EEVEE`。Cycles はタイムアウトするので使わない
- `scene.node_tree` は無い（コンポジタは `scene.compositing_node_group`）。コンポジタの Glare は真っ白になるので使わない（光は3Dの板で作る）
- `action.fcurves` は無い。`scene.eevee.use_ssr` は無い（`use_raytracing`）
- `spline.points.resize()` は無い → bmesh。`curve.fill_mode='BOTH'` は無い
- AgX は色が潰れる → Standard。`view_transform='None'` は無い
- 96フレーム一括はタイムアウト → 24ずつ4回

### 空を大きく見せる構図（ワードクラウド画面 SkyCam）
- 空グラデの MapRange が From Max -0.45 のままだと、上を向いたとき上空が一色になり境目に段差が出る → **From Max -1.0、ramp の位置を×0.45（最後だけ1.0）**
- ColorRamp が LINEAR だと色の切り替わり位置に線が見える → **B_SPLINE**
- 暗い時間帯にしたら水面の Emission（WaterFacet の `Emission`、0.30）も下げる（日没直後 0.20、ブルーアワー 0.12）。下げないと川だけ浮く
- 作業ファイル: `pk_pool_v1.blend`（v21B のコピー。SkyCam 位置 (5.5,5.5,1.6)・回転 (106°,0,130.75°)・lens 26 で空が上7割、地平線が上から約72%）
- **川→ワードクラウドの遷移**（ユーザー決定: 川=A夕暮れ → 遷移 A→B→C → ワードクラウド=C）: TransCam を RiverCam→SkyCam へ（位置 lerp・回転 slerp・smoothstep）。光と空は t0→0.5 で A→B、0.5→1 で B→C を補間。太陽（SunDisc/SunHaloObj）は消さずに t0→0.6 で z を -6 沈める。最後のコマは光の輪の残照が地平線に残る（これがワードクラウドの背景）
- **ワードクラウド画面のループ動画**（`pk_cloud_loop_final.mp4` → アプリの `cloud_bg.mp4`、2026-10-04）: `apply_t(1.0)`（SkyCam＋C の光）でフレーム 48〜143 の96コマ。波は96コマ周期なので 48 から始めると、最初のコマ＝遷移動画の最後のコマ（差0）で、そのままループする。1コマ約6〜8秒（空の構図は川より重い）→ 1回の指示は15コマまで（20コマで167秒）
- 最初のコマはメイン画面と一致させる。確認は `previews/v21b_bg.png`（540×960）と画素の平均差（今回 2.4/255）。ramp の位置×0.45 と MapRange -1.0 の組み合わせなら地平線〜Z0.45 の色は元と同じ

### 見た目
- 地面・水面を高さゼロの板にする → 平面に見える
- 地形の高さに乱数 → とげとげ。正弦波の合成で
- 三角錐の木・尖った山 → とげとげしい
- Emission を強く（0.5以上） → 陰影が消える
- Glossy を Add で足す／fac を上げる → 白飛び・割れたガラス。fac 0.03前後・rough 0.30
- 霞の start が近い → 全体がクリーム色
- 空グラデの Normal.Z は上空ほど負（From Max を -0.45 に）
- 水面に自分の影 → 硬い縞。`visible_shadow=False`
- 面の作成順で `material_index` を振る → 色がずれる。座標で振る
- 水面を川の形に切り抜く／縁まで波を立てる → 岸がのこぎり刃。一枚シート＋WaveMask
- 水面を全面同じ色 → 空と馴染まない。フレネル
- フレネルの切り替えが急（From Min 0.45） → 水面に横線
- カメラを川の中心に向けない → 片側の岸が広すぎる
- 偏りを直すために左右対称にする → 人工的（不採用）
- 全体をなめらかにする／木を丸く／木をリアルに → v9 の絵柄から離れて不採用
- 空に画面の半分 → 泡のスペースが足りない
- 手前の水面を平らにしすぎる → 青い板＋境目の横線
- 曲がり角の手前に木 → 奥の川と泡を隠す
- 泡を遠近どおりに縮める → 奥の文字が読めない
- 川をまっすぐ → 用水路
- 物の位置を「川からの距離」だけで決める → 画面の奥に集まって見えない／画面外に出る
- 花や草を一様にばらまく → 人工的。花畑とガマの株に
- 物を地面の端（|x|,|y|>14）に置く → 空に浮く
- **地面を ±17 だけで作る → 川の奥で地面の端が板のように見える**。外側に FarGround と FarWater を足す
- **遠くの地面を沈める → 地平線まで湖・海に見える**。上り坂を止めるだけにする
- **地面を広げたのに遠景の丘を元の距離（27〜40）に置いたまま → 丘が大地に埋もれ、霞で白く平らな塊になり、奥の川を隠して途切れて見える**（v20）。丘は地平線の向こう（距離70〜92）へ下げ、横に広く低く（scale 3.8〜5 × 高さ0.40〜0.55）
- 地形や範囲を変えたら、既存の遠景（丘・森）が埋もれていないか・川を隠していないかを同時に確かめる
- 星形のキラキラ → 世界観に合わない（不採用）
- 岩・小物を明るい色に → 夕日でピンクの卵に見える
- 「前の〜に戻して」をどの版か確かめずに作る → 遠回り。previews の画像で確かめる
