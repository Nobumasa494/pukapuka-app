# pukapuka 日記スキル

5つ目の画面「日記」を作る・直す・確かめるためのスキル。
**何を作るか・なぜかは `docs/SPEC.md`（第1部「気づきの日記」、第2部 G.）。決めたことは設計書に書く（`/pukapuka-spec`）。このスキルは、作り方・確かめ方のメモ。** 保存の決め方は `/pukapuka-db`、色と世界観は `/pukapuka-design`、重さは `/pukapuka-perf`。

---

## 1. 次にやること（2026-10-11 更新。ここから始める）

- **画面はできた（2026-10-11）**：水辺の月と星 →「日記」。カレンダー（書いた日に丸い印）→ 日を押す → 読む・書く・書き足す・直す・けす。下にその月の日記。右上の星で使い方、見本。web で通しで確かめた（`scripts/diary/*.mjs`）
- **スマホ（Galaxy S20）では、まだ見ていない**。キーボードで入力欄が隠れないか、開く速さ、戻ったあと川が動き出すか（`/pukapuka-perf`、`/pukapuka-night` の adb の道具）
- 未決：入口（メニューの「日記」でよいか）、曲

## 2. 一番大事な決まり

- **見た目は昼の空**（2026-10-11、ユーザー「日記は日中のイメージ」→「やっぱり昼の青空」「美しく、洗練されたデザインで」）。色・字・カレンダーの印の決まりは `/pukapuka-design` の「日記（昼）」

- **アプリは日記に何も言わない**。コメント・問い・まとめ・分析をしない。拾った言葉とつなげない（2026-10-11 ユーザー「画面は独立させるようにしているのにAIがコメントさせているのが方針に合わない」）
- 書いた数・連続日数・催促を出さない。カレンダーの印は「書いた日が分かる」ためだけ（数を数えない）
- 動物などの絵は出さない（ユーザー「くまのマークはいらんね」）

## 3. ファイルの地図

| ファイル | 何をする |
|---|---|
| `src/components/DiaryOverlay.tsx` | 画面のすべて。昼の空（`SKY`・雲 `Clouds`）、カレンダー（`monthCells`、マスの高さは44まで、書いた日は小さな点）、選んだ日のカード（読む・書く `TextInput multiline`・「けす」は二度押し）、その月の一覧（押すとその日を開いて上へ）、使い方 `INTRO_LINES`、見本 |
| `src/diary.ts` | 日付まわり：`parseDay`・`dayLabel`（10/11（日））・`monthCells`（日曜はじまり）。日の鍵は `src/period.ts` の `dayKey` |
| `src/diarySample.ts` | 見本の仮の日記（今日から数えた日に9つ。前の月にもかかる）。保存しない |
| `src/useDiary.ts` | `useDiaries`・`useDiaryActions`（`save(day, text)`・`remove(day)`）。ダミーの人（`?demo=1`）は保存しない |
| `convex/diary.ts` | `save`（1日1つ・同じ日はおきかえ・空なら消す・4000字まで）・`remove`・`list`。表は `convex/schema.ts` の `diaries`（`deviceId`・`day`・`text`・`savedAt`） |
| `src/app/index.tsx` | 月と星のメニューの「日記」、`openDiary`・`closeDiary`。開いている間は川の泡（`paused`）と動画を止める。動画で移らず、ふわっと重ねる（FadeIn 350ms） |
| `scripts/diary/web-test.mjs` | web（8091・`?demo=1`）：開く・使い方・見本・一覧から日を開く・前の月・戻る・もう一度開く。写真は `/tmp/pukapuka-screenshots/diary-*.png` |
| `scripts/diary/save-test.mjs` | テスト用の端末の目印で：今日書く → 印 → 書き足す → 前の日に書く → けす（最後に消すので、開発用 Convex に残らない） |

## 4. 確かめ方（直したら、この順で）

```bash
npx tsc --noEmit && npx eslint src/components/DiaryOverlay.tsx src/diary.ts src/useDiary.ts convex/diary.ts
npx convex dev --once                   # 表や関数を変えたとき（開発用。CONVEX_TMPDIR をスクラッチに）
node scripts/diary/web-test.mjs         # 8091 を立ててから
node scripts/diary/save-test.mjs
```

- 8091 は `npx expo start --web --port 8091`（ユーザーの 8081 は止めない。CI=1 はつけない）
- ヘッドレスのブラウザでは、戻るときに動画の自動再生の禁止（NotAllowedError）が出る。ほかの画面でも出るので数えない
- 「見本を見る」は、何もないときの真ん中と使い方の中の2つある。使い方の中のものは `.last()`
