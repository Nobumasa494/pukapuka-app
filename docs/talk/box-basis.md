# 名札（箱）の根拠：借りる分け方といまの127語の比べ（2026-10-13）

調べたもの（公式・研究の資料。確かめたところと、まだのところを分けて書く）

## 1. していること → 社会生活基本調査（総務省）

**確かめたこと**
- 1日の行動を **20種類** に分けて集計している（2016年・2021年とも）。大きく3つ：1次活動（睡眠・食事など）、2次活動（仕事・家事など義務的）、3次活動（自由に使える時間）
- 20種類：睡眠／身の回りの用事／食事／通勤・通学／仕事／学業／家事／介護・看護／育児／買い物／移動／テレビ・ラジオ・新聞・雑誌／休養・くつろぎ／学習・自己啓発・訓練／趣味・娯楽／スポーツ／ボランティア活動・社会参加活動／交際・付き合い／受診・療養／その他
- もう1つの調べ方「生活行動」：過去1年に何をしたかを、**5つの余暇活動**（学習・自己啓発・訓練／ボランティア活動／スポーツ／趣味・娯楽／旅行・行楽）ごとに、さらに**種類別**（例：スポーツなら「ウォーキング・軽い体操」「ジョギング・マラソン」など）に調べている

**まだ確かめていないこと**
- 「趣味・娯楽」「スポーツ」などの**種類の一覧そのもの**（全部で何種類か、名前）。e-Stat の統計表で確かめる

**いまの「していること」26語を当てはめると**

| 調査の分類 | いまの言葉 |
|---|---|
| 趣味・娯楽 | 作る・絵を描く・写真・植物を育てる・音楽・映画・ゲーム・読書・趣味（9語） |
| 家事 | 料理・片づけ |
| スポーツ | 運動・散歩（散歩は「ウォーキング・軽い体操」と思われる。要確認） |

| ボランティア活動・社会参加活動 | 誰かを手伝う |

| 買い物 | 買い物 |

**気づいたこと**
- 好奇心に関わるのは、ほぼ 3次活動（自由時間）。いまの言葉もそこに集まっている
- 「趣味・娯楽」1つに9語が入る。箱としては粗すぎる → 生活行動の**種類別の一覧**（ギター・登山・陶芸のような細かさ）を箱の土台にするのがよさそう

## 2. したいこと・好奇心 → 興味の6タイプ（ホランド、RIASEC）

**確かめたこと**
- 職業の興味を6つに分ける：現実的（物・道具・体を使う）／研究的（考える・調べる）／芸術的（作る・表す）／社会的（人を助ける・教える）／企業的（人を動かす・挑む）／慣習的（整える・記録する）
- 6つは六角形に並び、近いほど似ている。人は1つではなく2〜3の組み合わせ
- もとは**仕事の**興味の分け方。余暇やしたいことに使えるかは、別に確かめる必要がある

**いまの言葉との関係**：いまの「好奇心」14語（気になる・不思議…）は、興味の**向き**ではなく**気持ちの状態**。6タイプには当てはまらない。6タイプは「箱」ではなく、箱をまとめて見るときの**ものさし**に向く

## 3. 気持ち → 感情の円環モデル（ラッセル、1980）

**確かめたこと**
- 28の気持ちの言葉を、**快・不快**と**落ち着き・高ぶり**の2本の軸の円に並べた。人に似ている言葉どうしを分けてもらって作った
- 8つのまとまり（喜び・興奮・高ぶり・苦しさ・みじめさ・落ちこみ・眠さ・満ち足り）で見ることもある（後の研究による分け方。ラッセルの元の置き方とは限らない）

**まだ確かめていないこと**：28語の元の位置（論文本文）

**いまの言葉との関係**：いまの感情30語・身体19語は、この円のどこかに置ける。気持ちの箱は「円の8つのまとまり」くらいの粗さにまとめられる
