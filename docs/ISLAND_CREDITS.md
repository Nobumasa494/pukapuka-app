# 島の3D素材の出どころ

島（朝）の景色と言葉の植物は、Poly Pizza（https://poly.pizza）の素材を Blender で塗り直し、光を焼いて使っています。
CC-BY の素材は、アプリのクレジットに作者名を出す必要があります（書き方：「"モデル名" by 作者名 (poly.pizza) CC-BY」）。
Poly Pizza の API 規約により、クレジットには「3D モデル：Poly Pizza（https://poly.pizza）」も入れます。
